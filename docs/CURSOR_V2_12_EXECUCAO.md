# Execução v2.12 no Cursor — Release Gate, Deploy Humano e Verificação de Efeito\n\n## Objetivo\n\nExecutar um ciclo auditável em quatro etapas:\n\n1. gate pré-deploy;\n2. decisão humana de deploy;\n3. deploy com evidência real;\n4. verificação posterior do comportamento da implementação.\n\nA v2.12 não executa deploy, rollback ou alteração automática de regra.\n\n## Pré-requisito\n\nConcluir a v2.11 com post_merge_state=verified_healthy e rollback_readiness_status=ready.\n\n## 1. Gerar release gate\n\n    python scripts/create_release_deploy_gate_template_v2_12.py\n\nPreencher:\n\n- evaluated_at;\n- reviewer_role;\n- target_environment = hml ou prd;\n- release_version;\n- release_notes_ref;\n- deployment_plan_ref;\n- monitoring_plan_ref;\n- rollback_plan_ref;\n- predeploy_ci_status;\n- predeploy_security_privacy_status;\n- monitoring_readiness_status;\n- rollback_plan_verification_status;\n- change_window_status;\n- final_release_decision;\n- release_rationale.\n\nDecisões do gate:\n\n- eligible_for_human_deploy;\n- blocked;\n- defer.\n\n## 2. Validar release gate\n\n    python scripts/validate_release_deploy_gate_v2_12.py --input CAMINHO/release_gate.csv\n\nO release_commit_sha deve ser exatamente o merged_commit_sha verificado na v2.11.\n\n## 3. Gerar decisão humana de deploy\n\n    python scripts/create_human_deploy_decision_template_v2_12.py\n\nSomente release gates com final_release_decision=eligible_for_human_deploy aparecem.\n\n## 4. Validar decisão humana\n\n    python scripts/validate_human_deploy_decision_v2_12.py --input CAMINHO/deploy_decisions.csv\n\nValores:\n\n- approve_human_deploy;\n- reject_deploy;\n- defer_deploy.\n\nA decisão continua distinta da execução.\n\n## 5. Gerar template do deploy real\n\n    python scripts/create_deployment_record_template_v2_12.py\n\nO template pré-preenche:\n\n- environment = target_environment autorizado;\n- deployed_commit_sha = release_commit_sha autorizado.\n\nEsses valores não podem ser trocados silenciosamente.\n\n## 6. Validar deploy real\n\n    python scripts/validate_deployment_record_v2_12.py --input CAMINHO/deployment_record.csv\n\nO registro exige deploy_evidence_ref e verificações pós-deploy.\n\n## 7. Verificação de efeito\n\n    python scripts/create_effect_verification_template_v2_12.py\n    python scripts/validate_effect_verification_v2_12.py --input CAMINHO/effect_verification.csv\n\nA verificação observa comportamento técnico/operacional e não é inferência causal epidemiológica.\n\n## 8. Relatório estadual\n\n    python scripts/build_deployment_verification_report_v2_12.py\n\nO relatório consolida:\n\n- release gate;\n- decisão humana;\n- deploy com evidência;\n- verificação de efeito.\n\n## 9. Revisão visual\n\n    streamlit run app_review_streamlit.py\n\nUsar a aba Deploy e efeito v2.12.\n\n## Agentes\n\nExecutar:\n\n1. POS-MERGE;\n2. RELEASE-GATE;\n3. POS-DEPLOY;\n4. PRIVACIDADE;\n5. AUDITORIA;\n6. DOCUMENTACAO.\n\n## Travas\n\n- deploy_eligibility_is_not_deploy=true;\n- release_gate_required=true;\n- deploy_decision_is_not_deploy_execution=true;\n- deployment_record_requires_actual_deploy_evidence=true;\n- effect_verification_is_not_causal_inference=true;\n- automatic_deploy=false;\n- automatic_rollback=false;\n- automatic_rule_change=false;\n- patient_level_decision=false;\n- ambiente e commit implantados devem corresponder exatamente ao release gate;\n- identificadores pessoais do revisor não são armazenados;\n- promoção pública automática=false.\n
