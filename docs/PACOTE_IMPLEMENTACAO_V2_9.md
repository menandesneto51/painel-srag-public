# v2.9 — Pacote Controlado de Implementação\n\n## Objetivo\n\nPreparar uma implementação manual a partir de uma avaliação v2.8 aprovada.\n\n## Pré-condição\n\nSomente avaliações com final_decision = approve_for_implementation_branch podem gerar pacote v2.9.\n\n## Conteúdo do pacote\n\n- proposal_id;\n- evaluation_record_id;\n- proposta/regra de origem;\n- resumo da implementação;\n- arquivos-alvo;\n- testes requeridos;\n- critérios de aceitação;\n- plano de rollback;\n- evidências;\n- branch sugerida.\n\n## Segurança\n\nO pacote não cria a branch e não altera o repositório.\n\nTravas:\n\n- package_is_not_implementation=true;\n- manual_branch_required=true;\n- automatic_branch_creation_enabled=false;\n- automatic_code_edit_enabled=false;\n- automatic_commit_enabled=false;\n- automatic_merge_enabled=false;\n- automatic_deploy_enabled=false;\n- human_review_required=true.\n\n## Caminhos protegidos\n\nO validador rejeita caminhos absolutos, traversal com '..' e alvos protegidos como .env, data_raw/, data_internal/, .git/, secrets/ e credentials/.\n\n## Próximo passo\n\nSe o pacote for validado e revisado, a branch de implementação deve ser criada explicitamente por uma pessoa ou fluxo institucional autorizado. A branch recebe novamente testes, revisão e gates antes de qualquer merge.\n
