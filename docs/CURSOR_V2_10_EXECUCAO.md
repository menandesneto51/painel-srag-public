Gerar template\n\n    python scripts/create_merge_gate_template_v2_10.py\n\n## 2. Obter evidência do diff\n\nNa branch manual, registrar:\n\n- implementation_branch;\n- source_commit_sha;\n- implementation_commit_sha;\n- changed_paths.\n\nchanged_paths deve conter somente arquivos autorizados em target_paths do pacote v2.9.\n\n## 3. Preencher gates\n\nCampos:\n\n- diff_review_status;\n- scope_review_status;\n- ci_status;\n- regression_tests_status;\n- backtest_status;\n- epidemiology_revalidation_status;\n- statistical_revalidation_status;\n- security_privacy_review_status;\n- acceptance_criteria_status;\n- rollback_verification_status;\n- final_gate_decision;\n- gate_rationale.\n\nDecisões:\n\n- eligible_for_human_merge;\n- blocked;\n- defer.\n\n## 4. Validar\n\n    python scripts/validate_merge_gate_v2_10.py --input CAMINHO/gate.csv\n\n## 5. Gerar relatório\n\n    python scripts/build_merge_gate_report_v2_10.py\n\n## 6. Revisão visual\n\n    streamlit run app_review_streamlit.py\n\nUsar a aba Gate de merge v2.10.\n\n## Regra central\n\neligible_for_human_merge não significa merge executado.\n\n## Travas\n\n- merge_eligibility_is_not_merge=true;\n- automatic_commit_enabled=false;\n- automatic_merge_enabled=false;\n- automatic_deploy_enabled=false;\n- human_merge_required=true;\n- human_review_required=true.\n\n## Próximo passo\n\nUma pessoa revisa a branch/PR e decide explicitamente sobre o merge.
