# Execução v2.11 no Cursor — Merge Humano e Pós-Merge\n\n## Objetivo\n\nRegistrar a decisão humana sobre merge e, somente após evidência real de merge, validar o estado pós-merge e a prontidão de rollback.\n\n## 1. Gerar template de decisão humana\n\n    python scripts/create_human_merge_decision_template_v2_11.py\n\n## 2. Validar decisão humana\n\n    python scripts/validate_human_merge_decision_v2_11.py --input CAMINHO/decisoes.csv\n\nDecisões permitidas:\n\n- approve_human_merge;\n- reject_merge;\n- defer_merge.\n\napprove_human_merge registra aprovação humana, mas não executa o merge.\n\n## 3. Após um merge real, gerar template pós-merge\n\n    python scripts/create_post_merge_template_v2_11.py\n\n## 4. Registrar evidência pós-merge\n\nPreencher:\n\n- recorded_at;\n- reviewer_role;\n- merged_commit_sha;\n- merge_evidence_ref;\n- post_merge_ci_status;\n- smoke_test_status;\n- epidemiology_sanity_status;\n- security_privacy_check_status;\n- rollback_readiness_status;\n- post_merge_state;\n- verification_notes.\n\n## 5. Validar pós-merge\n\n    python scripts/validate_post_merge_v2_11.py --input CAMINHO/post_merge.csv\n\n## 6. Gerar relatório\n\n    python scripts/build_human_merge_report_v2_11.py\n\n## 7. Revisão visual\n\n    streamlit run app_review_streamlit.py\n\nUsar a aba Merge humano e pós-merge v2.11.\n\n## Estados pós-merge\n\n- verified_healthy;\n- needs_investigation;\n- rollback_consideration.\n\nverified_healthy exige:\n\n- CI pós-merge passed;\n- smoke test passed;\n- sanity epidemiológico passed;\n- segurança/privacidade passed;\n- rollback_readiness_status=ready.\n\n## Regras centrais\n\n- decisão de merge não é execução do merge;\n- registro pós-merge exige evidência explícita do merge;\n- registro pós-merge não é deploy;\n- rollback readiness não executa rollback.\n\n## Travas\n\n- merge_decision_is_not_merge_execution=true;\n- post_merge_record_requires_actual_merge_evidence=true;\n- post_merge_record_is_not_deploy=true;\n- automatic_merge_enabled=false;\n- automatic_deploy_enabled=false;\n- automatic_rollback_enabled=false;\n- human_merge_required=true;\n- human_post_merge_verification_required=true;\n- personal_identifier_storage=false.\n\n## Agentes\n\nExecutar:\n\n1. AGENTE-GATE-DE-MERGE;\n2. AGENTE-POS-MERGE;\n3. AGENTE-EPIDEMIOLOGIA;\n4. AGENTE-PRIVACIDADE;\n5. AGENTE-AUDITORIA;\n6. AGENTE-DOCUMENTACAO.\n
