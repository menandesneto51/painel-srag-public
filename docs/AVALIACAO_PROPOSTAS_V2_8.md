Apenas autoriza preparar uma branch separada de implementação.\n\n## Evidências para mudanças de lógica/threshold\n\n1. case review = passed;\n2. revisão epidemiológica = passed;\n3. backtesting = passed;\n4. revisão estatística = passed;\n5. documentação = passed.\n\n## Mudança exclusivamente documental\n\nExige case review, revisão epidemiológica e documentação aprovados. Backtesting e revisão estatística podem ser not_applicable.\n\n## Privacidade\n\nArmazenar apenas reviewer_role. Não armazenar nome, CPF, matrícula, e-mail ou outro identificador pessoal do revisor no dataset candidato.\n\n## Proteções\n\n- proposal_is_not_change = true;\n- decision_is_not_implementation = true;\n- automatic_rule_change_enabled = false;\n- automatic_threshold_change_enabled = false;\n- automatic_merge_enabled = false;\n- automatic_deploy_enabled = false;\n- human_approval_required = true;\n- personal_identifier_storage = false.\n\n## Implementação posterior\n\nUma proposta aprovada deve ser implementada em branch separada, novamente testada e revisada antes de qualquer merge ou deploy.\n
